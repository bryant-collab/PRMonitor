The control-plane change

Before F12

F10 and F11 can observe and gate versions, but the next action is not yet a durable scheduling contract.

  • No persisted quiet-period deadline.
  • No exact per-PR pending-batch lifecycle.
  • No Check Now request identity.
  • No global pause admission gate.

After F12

The main process can wait, batch, pause, resume, and recover without asking a renderer or model to own timing.

  • One immutable version set per PR, deduplicated.
  • New eligible feedback restarts that PR's deadline.
  • Paused work waits; it is not silently discarded.
  • Dispatch is rechecked and claimed once through F11.

Risks and handoff

What implementation must keep true

Clock jumps

Persist UTC deadlines and recompute due work on wake/restart. In-process timers are wakeups, never authority.

Claim races

F12 persists intent, then asks F11 to claim the exact set. A retry reads the winner instead of inventing a second operation.

Scope drift

F12 owns timing only. F10 owns observation, F11 owns eligibility/holds, F18 owns review work, and F19 owns tray presentation.
